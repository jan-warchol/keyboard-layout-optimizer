# keyboard-layout-optimizer

A one-handed (right-hand) layout for the Keyboardio Model 100, optimized from
timed key-sequence measurements on the real keyboard plus discomfort ratings,
weighted by what is actually typed by hand (keylogs, shell history).
Comfort first, speed second.

See [docs/design-principles.md](docs/design-principles.md) for the goals,
layout structure and scoring model,
[docs/measurement-plan.md](docs/measurement-plan.md) for the measurements, and
`python3 measure/measure.py --help` for running measurement sessions.
