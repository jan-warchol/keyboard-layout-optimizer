# Handoff (2026-11-21 evening)

Approach since 2026-11-21: **find which cost parameters change the layout
before measuring more** (option 1 of the earlier list). The pipeline runs
end to end: corpus → rough cost model → annealing optimizer → sensitivity
sweep. Details and results: [docs/optimizer.md](docs/optimizer.md).

## State

- **Corpus** (`analysis/corpus.py` → `analysis/corpus/*.tsv`): keylogs,
  task notes, shell history (commands and prose split by keystats'
  `split_history_prose.py`), corrected for current one-handed use with the
  user (git as `g`, no commits, git/Vim 0.3, `qg` soft break, pasted and
  dictated notes out). The user reviewed the statistics on a page
  generated by `analysis/corpus_report.py`; regenerate it after corpus
  changes if they want to look again.
- **Measurement sessions removed from the raw 2026 keylogs**
  (`keystats-data/backup/raw-2026-before-measurement-removal.tar.gz`,
  `remove_measurements.py`), 2026 reprocessed. Remove future sessions the
  same way, or keep keystats paused while measuring.
- **Cost model** (`optimizer/model.py`): phase 1-2a values plus guesses;
  scissors per finger pair and direction, full scissor factor.
- **Sensitivity** (three sweeps, the last two in
  `analysis/sensitivity-2026-11-21-*.txt`): the layout depends most on
  1. **index up + middle down scissor** (if 4-6× the guess of 30 ms/row:
     regret 1.2-3.1 ms/char) and whether **middle up + index down** is
     really nearly free (regret up to 1.2);
  2. **index same-finger cost** (1.8 at ±25%);
  3. **layer switch** (0.85), **different-finger base** (0.8),
     finger after Space (0.4).

  Everything else is noise (≤ 0.2), including pinky-up scissors (any good
  layout avoids them), middle-ring scissors, lateral stretch, row change,
  outward penalty, per-key efforts. Regret is out of ~160 ms/char; the
  noise of the last sweep ≤ 0.16. Not testable this way: effects the model
  lacks (hand shifts, redirects, trigram rolls).
- **Optimizer speed:** the annealing loop is compiled with numba
  (`uv sync` once; `uv run optimizer/anneal.py`, `uv run optimizer/sweep.py`).
  Full sweep in 5 min, a 3-parameter sweep in 30 s; warm starts make
  regret ≥ 0 with noise ~0.05. Latest sweep:
  `analysis/sensitivity-2026-11-21-numba.txt` (same ranking as above).
- **Layout:** the optimizer's current best is printed by
  `uv run optimizer/anneal.py` and at the top of the sweep files.
  Not yet reviewed with the user. Base layer, rows 1-3:
  `g o d l c f` / `i a t s n w` / `p e z m r /`, symbols on the number
  row, `u h k y b` etc. on layer 2. Many layouts score within 0.2 ms/char
  of each other, so details are arbitrary until the open costs are known.
